現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を体験します。変更の計画、コードの作成、動作のテスト、プル リクエストのレビュー、エージェントを使った作業の管理を繰り返しながら進めます。

## シナリオ

ボード ゲームのクラウドファンディングを提供する架空の企業 Tailspin Toys に、新しい開発者として参加します。チームのバックログは GitHub Issue として登録済みで、すぐに取り組めます。フィルターやページネーションなどの機能開発に加えて、アクセシビリティやコーディング規約などの品質改善も含まれています。

## 作業環境を選ぶ

GitHub Copilot は、どの環境で作業していても利用できます。開発方法に合った環境を選択してください。各ワークショップは個別のセットアップから始まり、共通の Tailspin Toys シナリオを使用します。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント アシスタントを使います。Plan と Autopilot の各モード、指示、スキル、カスタム エージェント、Playwright MCP、Agent Merge、便利なスラッシュ コマンドを試します。

### [GitHub Copilot app][app]

デスクトップ アプリでエージェント セッションを並行して実行し、セッション モードを切り替え、Canvas で共同作業し、GitHub Issue とプル リクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

非同期エージェントに GitHub Issue を割り当て、作業を導き、進捗を監視して、作成されたプル リクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに、Copilot Chat の agent モード、MCP サーバー、カスタム エージェントを利用します。
