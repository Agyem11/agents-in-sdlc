通过真实场景、完整应用和共享待办列表，探索 GitHub Copilot 在整个软件开发生命周期中的应用。你将通过迭代规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，提供带有开发者主题的桌游众筹服务。团队的待办事项已作为 GitHub 议题创建，可供你处理。其中既有筛选和分页等功能任务，也有无障碍功能和编码标准等质量改进任务。

## 选择工作环境

GitHub Copilot 可以在你工作的任何环境中使用。选择适合自己开发方式的环境。每个研讨会都会单独介绍环境设置，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。学习 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作使用画布，以及管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步智能体、引导其工作、监控进度并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
